## **PSD-to-JPG-Bulk-Converter**
This application helps you to convert large number of PSD files into JPG files.

---

## Usage

- Clone this application 

```bash
git clone https://github.com/DanushkaMadush/PSD-to-JPG-Bulk-Converter.git
```

- Navigate to project directory
```bash
cd PSD-TO-JPG-BULK-CONVERTER
```

- Install dependencies
```bash
pip install psd_tools
```

- Create Directories in the root
```plaintext
- PSD
- JPG
```

- Copy file paths to codebase
```plaintext
input_dir = r"YOUR PSD file path"
output_dir = r"YOUR JPG file path"
```

- Run the application
```python
python app.py
```
